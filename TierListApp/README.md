# Tier List for Apple

Native SwiftUI app for iPhone, iPad, and Mac. Open `../TierListApp.xcodeproj` in Xcode 15+, pick a destination, and press Run.

Full guide: [docs/SWIFT.md](../docs/SWIFT.md)

## Features

- S, A, B, C, D, and F rows styled like a classic tier list
- Compact rows on iPhone so the board stays usable on a small screen
- Photo library picker (multiple images)
- Drag an image onto a row to lock it in
- Drag between tiers or send an item back to the tray
