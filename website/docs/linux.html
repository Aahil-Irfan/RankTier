Linux

Debian, Ubuntu, Mint, Pop!_OS

sudo apt install ./tierlist_1.0.0_amd64.deb
tierlist

Fedora, RHEL, Rocky, Alma, openSUSE

sudo dnf install ./tierlist-1.0.0-1.x86_64.rpm
# or: sudo rpm -i ./tierlist-1.0.0-1.x86_64.rpm
tierlist

Arch, Manjaro, EndeavourOS

makepkg -si

Put the matching tarball next to the downloaded PKGBUILD first.

Any other distro

tar -xzf tierlist-1.0.0-linux-amd64.tar.gz
cd tierlist-1.0.0-linux-amd64
./install.sh
# or: ./tierlist

Alpine users typically need apk add gcompat before running the glibc binary, or run the web app instead.
