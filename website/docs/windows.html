Windows

  1. Download TierList-1.0.0-windows-amd64.exe (or the ARM64 exe on Snapdragon PCs).
  2. Double-click the file. Windows may show SmartScreen because the exe is unsigned — choose More info → Run anyway.
  3. Your browser opens on a local address such as http://127.0.0.1:…. Keep the console window open while you rank.
  4. Close the console window or press Ctrl+C to quit.

The zip download includes the same exe and a README. No installer and no admin rights are required.
